OPTION 1: DOWNLOAD FROM YOUTUBE (EASIEST)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

What you need:
✓ YouTube video link of Madhurashtakam
✓ Online converter tool
✓ 2-3 minutes of your time

Steps:

1. FIND THE SONG ON YOUTUBE:
   Go to YouTube and search:
   → "Madhurashtakam Krishna Das"
   → "Madhurashtakam Jagjit Singh"
   → "Madhurashtakam bhajan"
   
   Pick any version you like!
   (Recommended: Krishna Das version - most popular)

2. GET THE VIDEO LINK:
   → Right-click the video
   → Select "Copy video URL"
   → Or copy from address bar

3. CONVERT TO MP3 ONLINE:
   Go to: https://y2mate.com (or similar)
   → Paste the YouTube link
   → Select MP3 format
   → Download the file
   → Wait 30-60 seconds
   
   Alternative tools:
   • ytmp3.cc
   • onlinevideoconverter.com
   • youtubetomp3.online
   • yt2mp3.info

4. SAVE AS CORRECT NAME:
   After download, rename the file:
   OLD NAME: something like "video (1).mp3"
   NEW NAME: madhurashtakam.mp3 (EXACT!)
   
   How to rename in Windows:
   → Right-click file
   → Select "Rename"
   → Type: madhurashtakam.mp3
   → Press Enter

5. MOVE TO AUDIO FOLDER:
   → Go to: c:\Users\HP\Desktop\krishna-website\audio\
   → Drag the madhurashtakam.mp3 file into it
   → Verify it's there

6. TEST:
   → Open index.html in browser
   → Click the 🎵 Play button
   → Music should play! 🎶

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Audio button says "not found":
   → Verify file name is EXACTLY: madhurashtakam.mp3
   → Check file is in /audio folder
   → Make sure it's MP3 format (not WAV, M4A, etc.)
   → Refresh browser (Ctrl+F5)

❌ Downloaded file is .m4a or .wav:
   → Convert to MP3 first
   → Use: mediaio.com or convertio.co
   → Then follow placement steps

❌ Audio plays but cuts off:
   → File might be corrupted
   → Download again from fresh source
   → Try a different Krishna song

❌ Browser won't play audio:
   → Try different browser (Chrome, Firefox)
   → Clear browser cache (Ctrl+Shift+Delete)
   → Try converting with different tool
