IMAGE SPECIFICATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

How many:      8 images (more optional)
Format:        JPG or PNG (required)
Size:          400 x 400 px minimum (larger better)
Aspect ratio:  Square (1:1) - very important!
File size:     100-500 KB each (smaller = faster)
Quality:       High quality images

Resolution guidelines:
• 400x400 px: Minimum (acceptable)
• 600x600 px: Good quality
• 800x800 px: Excellent quality
• 1000x1000 px: Ultra high quality

STEP-BY-STEP PROCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: FIND AN IMAGE

Method A: Unsplash (Recommended)
   1. Go to: unsplash.com
   2. Search: "Krishna"
   3. Pick any image you like
   4. Click "Download"
   5. Save the file

Method B: Google Images
   1. Go to: google.com/images
   2. Search: "Krishna art"
   3. Find image you like
   4. Right-click > "Save image as"
   5. Save to your computer

STEP 2: RESIZE IMAGE TO SQUARE

Option A: Online (Easiest)
   1. Go to: canva.com (or pixlr.com)
   2. Upload your image
   3. Change dimensions to 600x600 px (or 800x800)
   4. Make square crop
   5. Download

Option B: On Windows
   1. Right-click image > Edit
   2. Microsoft Paint opens
   3. Image > Resize
   4. Set width and height same
   5. Save

STEP 3: SAVE AS JPG/PNG

If already JPG or PNG:
   → Keep it as is
   
If it's another format:
   → Online convert: convertio.co
   → Upload file > Select JPG or PNG > Download

STEP 4: RENAME FILE (Optional but helpful)

Suggested names:
   1. krishna-baby.jpg
   2. krishna-flute.jpg
   3. krishna-dancing.jpg
   4. krishna-radha.jpg
   5. govardhan.jpg
   6. krishna-teachings.jpg
   7. krishna-vrindavan.jpg
   8. krishna-divine.jpg

How to rename in Windows:
   1. Right-click file
   2. Select "Rename"
   3. Type new name
   4. Press Enter

STEP 5: MOVE TO /images FOLDER

Location: c:\Users\HP\Desktop\krishna-website\images\

1. Find your krishna-website folder
2. Open "images" folder
3. Drag & drop your images here
4. Verify they're inside

STEP 6: REFRESH WEBSITE

1. Open index.html in browser
2. Press Ctrl+F5 (hard refresh)
3. Scroll to Gallery section
4. Your images appear!

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Images not showing:

1. Check file location:
   → Go to: c:\Users\HP\Desktop\krishna-website\images\
   → Images should be there
   → Not in /audio or other folder

2. Check file names:
   → Should be: krishna-baby.jpg (exact!)
   → Not: Krishna Baby.jpg or krishna_baby.jpg
   → Case-sensitive on some systems

3. Check file format:
   → Should be: .jpg or .png
   → Not: .webp, .gif, .bmp
   → Convert if needed

4. Refresh browser:
   → Ctrl+F5 (hard refresh)
   → Close & reopen browser
   → Clear cache (Ctrl+Shift+Delete)

5. Check image size:
   → Should be at least 400x400 px
   → Minimum file size 50 KB
   → Maximum 10 MB

❌ Only some images showing:

1. Some images might be wrong format
2. Some might be too small
3. Some file names might be wrong
4. Refresh page again

❌ Emojis still showing:

1. Images might not be placed correctly
2. Filenames might not match expected names
3. Try renaming to exact names suggested
4. Refresh website (Ctrl+F5)

✅ WORKAROUND:
   Website works fine with emojis!
   Images are OPTIONAL enhancement.
   Emoji placeholders look great too.
