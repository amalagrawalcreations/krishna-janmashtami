🚀 QUICK START:
===============

1. OPEN THE WEBSITE:
   - Double-click index.html OR
   - Right-click index.html → Open with → Your Browser

2. ADD AUDIO (MADHURASHTAKAM):
   - Download or record Madhurashtakam song
   - Save as madhurashtakam.mp3 in the /audio folder
   - Click the play button in navbar to test

3. ADD IMAGES TO GALLERY:
   - Add images to the /images folder
   - Supported formats: JPG, PNG, WebP, GIF
   - Recommended size: 400x400 px or larger
   - Image names will automatically load in the gallery

🎧 AUDIO SETUP:
===============
1. Download Madhurashtakam song:
   - From YouTube, Spotify, or any music source
   - Recommended artists: Krishna Das, Jagjit Singh, or other devotional singers
   
2. Convert to MP3 (if needed):
   - Use online converter: Convert.online, CloudConvert, or FFmpeg
   
3. Add to project:
   - Place madhurashtakam.mp3 in /audio folder
   - Ensure filename is exactly: madhurashtakam.mp3
   - Refresh website to test

📸 GALLERY SETUP:
=================
1. Find Krishna images:
   - Google Images (search "Lord Krishna" or "Krishna Art")
   - Unsplash, Pexels, Pixabay (free stock photos)
   - Your own photos

2. Prepare images:
   - Crop to square (1:1 aspect ratio)
   - Resize to 400-800 px for web
   - Save as: krishna-baby.jpg, krishna-flute.jpg, etc.
   - Use format: Krishna-[name].jpg (all lowercase)

3. Add to gallery:
   - Place in /images folder
   - Refresh website
   - Gallery will automatically load all images!

🆘 TROUBLESHOOTING:
===================

❌ Audio not playing?
→ Check if madhurashtakam.mp3 is in /audio folder
→ Check browser console (F12) for errors
→ Try MP3 format if WAV doesn't work
→ Ensure file is not corrupted

❌ Images not showing?
→ Check /images folder for your images
→ Verify filenames match expected names
→ Try JPG or PNG format
→ Ensure images are web-optimized (not too large)

❌ Website looks broken?
→ Clear browser cache (Ctrl+Shift+Delete)
→ Try different browser
→ Check console for JavaScript errors (F12)
