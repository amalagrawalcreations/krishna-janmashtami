🎧 AUDIO SETUP GUIDE:
====================

1. Find Madhurashtakam:
   - YouTube: "Madhurashtakam Krishna Das"
   - Download tools: Y2mate, yt-dlp
   - Or search: Spotify, SoundCloud

2. Convert to MP3:
   - If needed, use: Online-Convert.com
   - Or: Audacity (free desktop app)

3. Add to project:
   - File name: madhurashtakam.mp3 (exact!)
   - Folder: krishna-website/audio/
   - File size: should work (preferably <5MB)

4. Test:
   - Refresh website
   - Click play button
   - Should play!

📸 GALLERY IMAGE SETUP:
======================

1. Find images:
   - Google Images ("Krishna art")
   - Unsplash, Pexels, Pixabay
   - Your own photos
   - Pinterest

2. Prepare images:
   - Crop to square (1:1 aspect ratio)
   - Resize: 400-800 px recommended
   - Compress for web
   - Save as JPG or PNG

3. Add to project:
   - Folder: krishna-website/images/
   - Optional names: krishna-baby.jpg, etc.
   - Works with any image name!
   - Refresh website - auto-loads!

4. How many images?
   - Default: 8 slots (can add more)
   - Can be any number
   - Better with consistent sizing

🆘 QUICK TROUBLESHOOTING:
=========================

Website won't open:
→ Try another browser
→ Check Windows file associations
→ Use "Open with" context menu

Audio not playing:
→ File must be named: madhurashtakam.mp3
→ Must be in /audio folder
→ Try MP3 format
→ Check browser console (F12)

Images not showing:
→ Place in /images folder
→ Check image format (JPG/PNG)
→ Verify file size isn't too large
→ Try different image file
→ Clear browser cache

Navigation not working:
→ Refresh page
→ Clear browser cache
→ Check browser console
→ Try different browser
